# SORIDRAW 90차 - 뮤직노트 뒤로가기 저장 차단

## 기준
- SORIDRAW_89차_뮤직노트_편집덮어쓰기방지.zip

## 수정 파일
- src/pages/FavoritesPage.tsx

## 수정 내용
- 곡 편집 화면에서 브라우저/앱 뒤로가기 또는 닫기 시 Firestore 저장이 실행되지 않도록 차단.
- 저장은 사용자가 편집 영역의 체크/저장 버튼을 눌렀을 때만 실행되도록 변경.
- 곡 전환 중 이전 곡의 임시 draft가 다른 곡 ID에 붙는 위험을 제거하기 위해 detail 화면 진입 시 현재 selectedSong 원본값으로만 편집 상태를 초기화.
- 저장 실행 시 targetSongId를 payload에 고정하여 저장 중 selectedSong 상태가 바뀌어도 다른 곡 ID로 저장되지 않도록 보강.

## 데이터 안전
- Firestore 구조 변경 없음.
- Auth/Functions/Rules 변경 없음.
- 기존 사용자 데이터 마이그레이션 없음.

## 확인 방법
1. 뮤직노트에서 곡 A 상세/편집 화면 진입.
2. 아무것도 저장하지 않고 뒤로가기.
3. '수정되었습니다' 토스트가 뜨지 않는지 확인.
4. 곡 B 상세/편집 화면 진입 후 뒤로가기.
5. 곡 B가 곡 A 내용으로 바뀌지 않는지 확인.
6. 실제 수정이 필요할 때는 편집 후 체크/저장 버튼을 눌렀을 때만 저장되는지 확인.
