## 변경 내용
- 뮤직노트 더보기 메뉴의 `수노 URL 수정/제거` 표기를 `수노 URL 연결`로 통일.
- 더보기 메뉴에서 수노 URL 연결을 누르면 별도 긴 URL 전용 팝업을 열지 않고, Detail & Edit 화면을 열어 내부 수노 URL 입력 섹션으로 이동하도록 변경.
- 모바일에서 URL 전용 팝업이 화면처럼 크게 뜨고 키보드가 자동으로 열리는 문제를 차단.
- Detail & Edit 화면의 수노 URL 제거 아이콘 버튼 제거.
- 수노 URL 입력칸 2개를 모두 비운 뒤 저장하면 연결 해제되도록 변경.
- Firestore/Auth/Functions/Rules는 수정하지 않음.

## 확인 방법
1. 뮤직노트 목록에서 곡 더보기 메뉴를 연다.
2. `수노 URL 연결`을 누른다.
3. 별도 URL 전용 팝업이 뜨지 않고 Detail & Edit 화면 안의 수노 URL 연결 섹션으로 이동되는지 확인한다.
4. 모바일에서 키보드가 자동으로 펼쳐지지 않는지 확인한다.
5. URL 2개를 모두 지우고 저장하면 수노 URL 연결이 해제되는지 확인한다.
